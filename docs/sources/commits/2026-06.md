lines, and 328 files / +9.8k −3.1k lines.

- `command.json` went from 23 to 76 entries (+53): Core (params, transform, views, sheets,
  viewports, view filter, tags, warnings, reference plane, shared and global params), MEP (7),
  Family (project and editor params) and Arch (wall, floor, ceiling, opening, room plus extras). It
  touched 53 TS tool files. The commit's own `TOOLSET_ROADMAP.md` still said "33 commands", so the
  doc lagged the code from the first day.

  starting from 33 commands), `SPECIALIST_ARCHITECTURE.md` (domains from API namespaces, persona
  design) and `SMOKE_TEST.md`.
- Hooked the plugin into CEM_RibbonUI (`Application.cs` stripped of UI, `SocketService` tweaks), and
  added `server/manifest.json` and `.mcpbignore` with a committed `cem-revit-ai.mcpb`.
